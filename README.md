# Quantum Toeplitz Benchmark

This repository contains the source code and benchmarking scripts for the manuscript: **"Evaluating quantum algorithms for structured matrices: A NISQ-era study of Toeplitz operators."**

## Requirements
To run this code, you will need to install the following Python packages:
* `qiskit`
* `qiskit-aer`
* `numpy`
* `pandas`
* `scipy`
* `matplotlib`

## Usage
Run the main script to generate the noisy simulation data, CNOT breakdown tables, and resource plots:
`python benchmark.py`
